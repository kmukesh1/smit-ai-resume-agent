# SMIT AI Resume Agent

ATS-ready one-page campus resume builder for **SMIT CSE** students.

Created by **Asst. Prof. Mukesh Kumar**, CSE Department, SMIT.

## Features

- Guided form and Quick Paste
- Track templates: SDE / Full Stack, AI & Data Science, Cloud / DevOps
- Live 1-page ATS preview
- Sample SMIT student profile
- STAR bullet polish (optional API key)
- Print / Save as PDF

## Run locally

```bash
npm install
npm run dev
```
